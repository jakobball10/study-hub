How to install

Your device

Android

  1. Open this page in Google Chrome.
  2. Tap Install the app above, or ⋮ → Add to Home screen.
  3. Tap Install.

Use Chrome. Some other browsers make an app package that newer Android blocks as "built for an older version". If you see that, choose Create shortcut instead.

Your device

iPhone or iPad

  1. Open this page in Safari.
  2. Tap Share (square with an up arrow).
  3. Tap Add to Home Screen → Add.

Only Safari can install apps on iPhone, so copy the link across if you're in Chrome.

Your device

Computer

  1. Open this page in Chrome or Edge.
  2. Click Install the app above, or the install icon in the address bar.
  3. It opens in its own window.

Mac Safari: File → Add to Dock.
